PART 1 · SKILLS

A Skill Is a Recipe Card Claude Follows

  • A folder with one file: SKILL.md.
  • Loads only when needed, unlike CLAUDE.md.
  • If you can write a checklist, you can write a skill.
Your standard operating procedure, stored where Claude can find it.Source: code.claude.com/docs/en/skills
PART 1 · ANATOMY
LIVE DEMO

SKILL.md: Frontmatter + Instructions

  • name becomes the /command.
  • description is the trigger.
  • The body is the recipe.
---
name: standup-summary
description: Summarize standup
  notes into a digest. Use when
  the user says "summarize the
  standup".
---

# Standup Summary
1. Read the notes file.
2. Pull blockers + owners.
3. Save to outputs/.

PART 1 · WHERE SKILLS LIVE

Personal Skills Follow You. Project Skills Stay in the Repo.

PERSONAL
~/.claude/skills/<name>/
  • Every project you open.
  • Only you.
PROJECT
.claude/skills/<name>/
  • This repo only.
  • Shared with the team via git.
Global skills do not travel to cloud routines. Commit a skill to the repo if a routine needs it.
PART 1 · FOLDER

One Folder Per Skill. SKILL.md Under 500 Lines.

  • SKILL.md is the only required file.
  • Move long reference docs into references/.
  • Scripts in scripts/, templates in assets/.

  references/
    style.md      <- on demand
  scripts/
    chart.py      <- executed
  assets/

PART 1 · WHEN TO MAKE ONE

Once Is a Prompt. Twice Is a Skill.

SKIP THE SKILL
  • One-off task.
  • Format still changing.
  • A single fact or rule: CLAUDE.md.
MAKE THE SKILL
  • Pasted the same steps twice.
  • Runs on a cadence.
  • You can write the steps down.
Can't write the steps down? It is a problem to think through, not a skill yet.

REFERENCE · GLOSSARY

Glossary

Skill
A SKILL.md recipe Claude loads when its description matches.
Frontmatter
The name + description block at the top of SKILL.md.
Slash command
Anything you run by typing /: built-in or skill.
$ARGUMENTS
Text typed after a command, passed to the skill.
MCP server
A connector that lets Claude use another app.
.mcp.json
Project file that shares MCP servers with the team.
Plugin
A box of skills, agents, hooks and MCP servers.
Progressive disclosure
Description always, body on trigger, files on demand.
REFERENCE · FAQ

Four Questions You Will Be Asked at Work

1
Skill or slash command?
Same thing now. Custom commands were merged into skills.
2
MCP vs API?
An API differs per app. MCP wraps any app's actions in one standard shape.
3
Does a project skill work elsewhere?
No. Put it in ~/.claude/skills/ for every project.
4
Do 50 skills or MCPs slow Claude down?
Barely. Only names and descriptions load until one is used.
