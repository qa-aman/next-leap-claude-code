8. Q&A entries, new shape

KCS + Diátaxis

Q427: The install finished, but the terminal says "claude is not recognized". What now?

Asked by
Praseetha, verbatim: "It just says, Cloud is not recognized or something like that."
Environment
Windows, PowerShell, fresh native install
Answer
Open a new terminal and run claude --version again. If it still fails, follow "Fix your PATH" in the troubleshooting page.
Cause
The install folder is not on PATH yet, and the old terminal window does not see the change
Type
How-to
Sources
Troubleshoot installation and login (verified 17-10-2026)

Q436: Are plugins in Claude's marketplace safe for a company that bans open-source tools?

Asked by
Sivaraj
Environment
Any plan. Applies to every marketplace, including claude-plugins-official
Answer
Being listed is not a security review. The official marketplace includes partner and third-party plugins. Review each plugin's Will install list in /plugin before you install it.
Cause
Plugins can run code with your permissions, and Anthropic does not review third-party marketplaces
Type
Explanation Corrects the in-class answer
